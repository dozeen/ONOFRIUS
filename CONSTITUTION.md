# ONOFRIUS CONSTITUTION

Version: Alpha 0.2

---

# 1. Event First

Everything begins with an Event.

No module acts without an Event.

---

# 2. Cognitive Pipeline

Every Event may pass through:

Perception

↓

Attention

↓

Memory

↓

Reasoning

↓

Decision

↓

Prompt

↓

Verification

↓

Response

---

# 3. Persistent Intelligence

Knowledge must survive process restarts.

Memory is a first-class citizen.

---

# 4. Modular Architecture

Every capability is implemented as an independent module.

Modules communicate only through defined interfaces.

---

# 5. Explainability

Every important decision should be explainable.

---

# 6. Privacy by Design

Personal data belongs to the Owner.

The framework must never expose personal information.

---

# 7. Release Certification

Every public release must pass Forge certification.

---

# 8. Open Architecture

Every component should be replaceable without modifying the Kernel.

---

# 9. Cognitivo ma non Personale

ONOFRIUS è cognitivo ma non personale.

Il software contiene esclusivamente il motore cognitivo, gli algoritmi e la logica. Tutta la conoscenza personale, le identità, i contatti, la memoria, gli eventi, le preferenze e le configurazioni vengono create o importate esclusivamente durante il bootstrap sul computer dell'utente. Nessun dato personale deve essere distribuito insieme al software.

---

# Motto

Every conversation begins with an Event.

Every Event may become Knowledge.

Every Knowledge may improve Intelligence.
